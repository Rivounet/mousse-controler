# Sources techniques

- [Microsoft — Bluetooth GATT Server](https://learn.microsoft.com/windows/apps/develop/devices-sensors/gatt-server)
- [Microsoft — GattServiceProvider](https://learn.microsoft.com/uwp/api/windows.devices.bluetooth.genericattributeprofile.gattserviceprovider)
- [Microsoft — DeviceInformationCustomPairing](https://learn.microsoft.com/uwp/api/windows.devices.enumeration.deviceinformationcustompairing)
- [Microsoft — unsigned MSIX packages](https://learn.microsoft.com/windows/msix/package/unsigned-package)
- [Microsoft — desktop app execution aliases](https://learn.microsoft.com/windows/uwp/porting/desktop-to-uwp-extensions)

Les sources servent à justifier la capacité manifeste Bluetooth, la cérémonie
`ConfirmOnly` et la stratégie de paquet. Les résultats matériels proviennent des
deux machines et sont publiés uniquement sous forme expurgée.
